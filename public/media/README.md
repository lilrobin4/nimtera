# NimTera introduction

nimtera-intro.mp4 is a 20-second silent walkthrough made from five genuine NimTera interface captures with explanatory Indonesian text. Each scene is labeled DEMO TAMPILAN / TESTNET. Shop, catalog and order data are illustrative; no production account, real payment or wallet approval was created for the video. The checkout is shown before payment, not as a fabricated success.

Scenes: overview, seller registration without mandatory 2FA, product management, customer catalog, testnet order review. A poster and Indonesian WebVTT captions accompany the video. The homepage also provides a text guide/transcript in all six interface languages.

UI capture source: scripts/capture-intro.mjs (local-preview-only; GET API fixtures, no write requests). Product photo sources: ../products/CREDITS.md. This asset is a visual introduction, not proof of on-device Nimiq Pay compatibility or a live chain transaction.
