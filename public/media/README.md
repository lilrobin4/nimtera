# NimTera introduction

nimtera-intro-nim-en.mp4 is a 20-second silent walkthrough made from genuine English-language NimTera interface captures, with English explanatory text and captions. Each scene is labeled VISUAL DEMO / TESTNET. Shop, catalog and order data are illustrative; no production account, real payment or wallet approval was created for the video. The checkout is shown before payment, not as a fabricated success.

Scenes: overview, seller registration without mandatory 2FA, product management, customer catalog plus the shop-operated cashier screen, and NIM testnet order review showing a 40 NIM subtotal plus 0.01 NIM unique adjustment (40.01 NIM total). The last scene illustrates automatic monitoring without requiring hash entry; it does not show or claim a real confirmed transfer. The video shows both the approved night appearance and new ivory/gold day appearance. Polygon and other token routes have been removed. Customers can open a shop link or choose menu items on the shop/restaurant's cashier screen; this does not give unauthenticated customers access to seller administration. An English poster and WebVTT captions accompany the video. The homepage text guide/transcript remains available in all six interface languages.

Sources: scripts/capture-intro.mjs (local-preview-only; GET API fixtures, no write requests) and scripts/render-intro.py (Pillow/imageio-ffmpeg; optional asset-authoring dependencies, not required for the app build). Product photo sources: ../products/CREDITS.md. This visual guide is not proof of on-device Nimiq Pay compatibility or a live chain transaction.

The README gallery images are genuine UI captures from the same isolated fixture run, labeled as illustrative Testnet data. They do not depict a real merchant payment.
